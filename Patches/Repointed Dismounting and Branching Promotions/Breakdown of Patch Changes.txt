All addresses used in the discussion of the changes made by this patch will be for an unheadered ROM.

Combined Table of Class Associations
====================================

This table starts at $05F1B2 and consists of 63 entries that are 8 bytes long, one for each playable character. The entries are ordered by character number - so the first entry is Sigurd's, the second entry is for Naoise, etc.

Each entry has 4 pairs of 1 byte class numbers, listing the number for the mounted class first and the dismounted class second. The first pair is used for the character's initial class, the second pair is the character's promotion choice if you press Y on the promotion screen, the third pair is the character's promotion choice if you press X on the promotion screen, and the fourth pair is the character's promotion choice if you press R on the promotion screen. Any entry that isn't applicable for a particular character (a dismounted class entry for a character that starts off in an infantry class, for example) is set to FF.

The original table used for associating characters with their promoted class (which starts at $03833C) has had all of its entries set to FF.

Skill Changes
=============

The Dismount skill has been added to all of the mounted classes that didn't already have it and Naoise has been given Dismount as a character skill. The latter isn't important because of the next change, though.

Removal of Character Dismount Skill Check
=========================================

At $05E6B1, a jump to another section of code that happens if a check to see if the active character has the Dismount skill fails is replaced with NOPs, effectively treating all characters as if they have the Dismount skill.
